# Site mama

Dit is een eenvoudige website voor GitHub Pages. De site bestaat uit gewone bestanden:

- `index.html` voor de tekst en structuur
- `styles.css` voor de vormgeving
- `script.js` voor kleine automatische dingen
- `assets/hero-workspace.jpg` voor de grote foto bovenaan

## Online zetten via GitHub Pages

1. Maak op GitHub een nieuwe repository, bijvoorbeeld `site-mama`.
2. Upload alle bestanden uit deze map naar die repository.
3. Ga in GitHub naar `Settings` en daarna `Pages`.
4. Kies bij `Build and deployment` voor `Deploy from a branch`.
5. Kies branch `main` en folder `/root`.
6. Klik op `Save`.

Daarna staat de site meestal binnen een paar minuten online op:

```text
https://gebruikersnaam.github.io/site-mama/
```

## Nog invullen

Vervang in `index.html` vooral:

- `Naam van je moeder`
- `plaatsnaam`
- de drie diensten
- telefoonnummer
- e-mailadres
- de tekst bij `Over haar`

Als er een echte foto is, vervang dan `assets/hero-workspace.jpg` of voeg een portret toe in de over-sectie.
